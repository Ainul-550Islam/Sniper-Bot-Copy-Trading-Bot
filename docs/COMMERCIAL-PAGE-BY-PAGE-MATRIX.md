# COMMERCIAL-PAGE-BY-PAGE-MATRIX.md
## Control Plane Page-by-Page Architectural Matrix

- **Date:** 2026-10-03
- **Scope:** Every Next.js 16 Control-Plane Route, User Actions, Backend API Endpoints, and Entitlement Boundaries.

---

### Page-by-Page Specifications

| # | Route | User Actions | Backend Endpoints | Auth / RBAC Requirements | Data Source / Truth | Known Limitation |
|:---|:---|:---|:---|:---|:---|:---|
| 01 | `/` | Sign in, register, switch tenant organization | `POST /api/saas/sessions`, `POST /api/saas/users`, `GET /api/saas/users/me` | Public landing / Bearer session token | SaaS PostgreSQL / Memory Session Store | In-memory token resets on hard browser reload |
| 02 | `/trading` | High-level portfolio overview, module toggles, quick strategy access | `GET /api/tenant/orders`, `GET /api/tenant/positions`, `GET /api/tenant/reports/pnl`, `GET /api/tenant/bots` | Bearer Token + Tenant Context (`x-organization`) | PostgreSQL Trading Data Plane | Requires active attached trading database |
| 03 | `/trading/sniper` | Monitor AMM launches, toggle Sniper engine, view latency | `GET /api/tenant/sniper/status`, `POST /api/tenant/sniper/controls`, `GET /api/tenant/sniper/config` | Permission `BotRead` / `BotStart` / `BotStop` | Yellowstone Geyser gRPC + Sniper Module Runtime | Real-time launch landing rate requires funded mainnet wallet |
| 04 | `/trading/sniper/config` | Update entry sizing, liquidity filters, slippage, anti-MEV protection | `GET /api/tenant/sniper/config`, `PUT /api/tenant/sniper/config` | Permission `BotManage` + Tenant Scope | Tenant Config Store / Data Plane | Validation enforces positive liquidity & non-zero priority fee |
| 05 | `/trading/copy` | View tracked wallets, mirror status, execution counts | `GET /api/tenant/copy/status`, `POST /api/tenant/copy/controls`, `GET /api/tenant/copy/leaders` | Permission `BotRead` / `BotStart` / `BotStop` | Copy Module Runtime + PostgreSQL | Quality of mirrored trades depends on tracked wallet selection |
| 06 | `/trading/copy/config` | Add/remove leader wallets, set allocation per trade, max USD exposure | `GET /api/tenant/copy/config`, `PUT /api/tenant/copy/config`, `GET /api/tenant/copy/leaders` | Permission `BotManage` + Tenant Scope | Tenant Copy Repo / Config Store | Wallets must be valid Base58 Solana public keys |
| 07 | `/trading/polymarket` | Explore prediction markets, inspect CLOB orders, view reconciliation drift | `GET /api/tenant/polymarket/status`, `POST /api/tenant/polymarket/controls`, `GET /api/tenant/polymarket/orders`, `GET /api/tenant/polymarket/reconciliation` | Permission `OrderRead` / `ReconciliationRead` | Polymarket Module + CLOB API | Live orders require funded Polygon USDC key |
| 08 | `/trading/polymarket/config` | Configure condition subscriptions, spread thresholds, order repricing | `GET /api/tenant/polymarket/config`, `PUT /api/tenant/polymarket/config` | Permission `BotManage` + Tenant Scope | Polymarket Config Store | Spread threshold prevents un-profitable market making |
| 09 | `/trading/telegram` | Bind/unbind Telegram chat ID, inspect alert dispatcher status | `GET /api/tenant/telegram/status`, `PUT /api/tenant/telegram/binding`, `DELETE /api/tenant/telegram/binding` | Permission `TenantRead` / `TenantUpdate` | Telegram Control Plane Store | Bot token configured at deployment level |
| 10 | `/trading/orders` | Search/filter orders, view execution traces, cancel pending orders | `GET /api/tenant/orders`, `POST /api/tenant/orders/:id/cancel` | Permission `OrderRead` / `OrderCancel` | PostgreSQL `orders` table (keyset paginated) | Cancelling filled orders is rejected server-side |
| 11 | `/trading/positions` | Track open positions, entry vs mark prices, realized gains | `GET /api/tenant/positions`, `GET /api/tenant/reports/pnl` | Permission `PositionRead` / `ReportRead` | Double-entry accounting ledger & position store | Mark prices derived from AMM pool ratios |
| 12 | `/trading/executions` | Filter execution records by date window, inspect Solscan tx links | `GET /api/tenant/executions` | Permission `ExecutionRead` | PostgreSQL `executions` table | Solana Explorer links depend on public internet access |
| 13 | `/strategies` | Browse saved strategy templates, create/duplicate/archive templates | `GET /api/tenant/strategies`, `POST /api/tenant/strategies`, `PUT /api/tenant/strategies/:id` | Permission `StrategyRead` / `StrategyManage` | Tenant Strategy Repository | Custom template persistence |
| 14 | `/backtests` | Configure historical period, slippage/fee model, execute backtest | `GET /api/tenant/backtests`, `POST /api/tenant/backtests` | Permission `BacktestExecute` | Backtesting Engine + Historical Tick Logs | Relies on historical pool launch snapshots |
| 15 | `/markets` | Search pairs across Raydium, Pump.fun, PumpSwap, and Polymarket | `GET /api/tenant/markets` | Permission `MarketRead` | DEX Market Screener Feed | Real-time market depth requires active websocket connection |
| 16 | `/billing` | Self-service plan upgrade, view usage limits, inspect invoices | `GET /api/saas/billing/status`, `GET /api/saas/usage/limits`, `POST /api/saas/checkout`, `GET /api/saas/invoices` | Permission `BillingRead` / `BillingManage` | Stripe/Paddle Billing Store & Usage Evaluator | Hosted checkout requires configured provider keys |
| 17 | `/custody` | Verify KMS/Vault health, list signers, trigger zero-downtime rotation | `GET /api/saas/custody/profiles`, `GET /api/saas/custody/health`, `POST /api/saas/custody/rotations` | Permission `CustodyRead` / `CustodyManage` | AWS KMS / HashiCorp Vault Signer Registry | Hardware HSM required for institutional FIPS isolation |
| 18 | `/integrations` | Monitor Yellowstone Geyser, Jito MEV, and RPC endpoint health | `GET /api/tenant/integrations` | Permission `InfrastructureRead` | Infrastructure Health Probe Registry | Ping RTT measured against active cluster endpoints |
| 19 | `/onboarding` | Step-by-step progress checklist for trading desk readiness | `GET /api/tenant/onboarding`, `POST /api/tenant/onboarding/complete` | Permission `TenantRead` | Onboarding State Store | Progress state saved per tenant organization |
| 20 | `/settings/team` | Invite members, modify RBAC roles, revoke organization access | `GET /api/saas/organizations/:id/members`, `POST /api/saas/organizations/:id/members` | Permission `UsersRead` / `UsersManage` | SaaS Membership & RBAC Store | Primary owner cannot be revoked without ownership transfer |
| 21 | `/settings/security` | Generate scoped API keys, revoke keys, view session tokens | `GET /api/saas/api-keys`, `POST /api/saas/api-keys`, `DELETE /api/saas/api-keys/:prefix` | Permission `ApiKeysManage` | SaaS API Key Store (SHA-256 hashed) | Plaintext secret displayed once upon creation |
| 22 | `/settings/data-lifecycle` | Trigger deterministic audit exports, request account closure/purge | `GET /api/saas/data-lifecycle/:id/status`, `GET /api/saas/exports`, `POST /api/saas/organizations/:id/suspension` | Permission `TenantManage` / `AuditExport` | Statutory Retention & Data Lifecycle Engine | Closure is irreversible and revokes all credentials |
